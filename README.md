# dll_inject

#### 介绍
DLL注入器
![输入图片说明](https://foruda.gitee.com/images/1732838178276776238/003e880b_9299190.png "屏幕截图")

功能介绍

-提供进程列表方便选择注入目标

-界面上所有状态在软件下次打开将原样恢复

-窗口hook提供追踪查找窗口方便进行HOOK消息钩子
